## 🌟 特性 (Features)

OpenWrt-App 是一个收集 OpenWrt/ImmortalWrt 路由客户端应用的工具，通过Actions每周运行自动更新！
本仓库的 IPK及APK 文件来自多个项目，版权归原作者，见 README 列表。
